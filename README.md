# Verse

作詞作曲のための「曲」を1件ずつ管理する、**完全ローカル・課金ゼロ**のWebアプリ（PWA）です。
1曲に対して **基本情報 / 歌詞（セクション対応）/ ボイスメモ（音声）/ 動画** を紐づけて管理できます。
音声・動画は外部に送信せず、**あなたの端末内（ブラウザのIndexedDB）にのみ保存**され、アプリ内でそのまま再生できます。

- フレームワーク・外部ライブラリ・ビルドツールは一切不使用（素の HTML / CSS / JavaScript）
- 通信・外部サーバー・データベース・月額課金は一切なし
- PC・スマートフォン両対応（レスポンシブ）、配色はモノトーン
- PWA対応（オフライン利用・ホーム画面追加）

## 機能一覧

| 分類 | 内容 |
|---|---|
| 曲管理 | 曲名 / 作成日 / 更新日 / ステータス（アイデア・作詞中・作曲中・デモ・完成）/ タグ |
| 歌詞 | テキスト入力。`[Intro] [Aメロ] [Bメロ] [サビ] [2番] [ラスサビ]` などセクション記法に対応（プレビューで見出し表示） |
| ボイスメモ | 音声ファイルをアップロードして保存・再生 |
| 動画 | 動画ファイルをアップロードして保存・再生 |
| CRUD・検索 | 追加 / 編集 / 削除 / 曲名・歌詞・タグ・ステータス横断検索 |
| ファイル再生 | アプリ内のカスタムプレイヤー（再生・一時停止・シークバー・時間表示） |
| バージョン管理 | 歌詞＋基本情報のスナップショット保存・差分表示・復元（※音声・動画は含みません） |
| バックアップ/復元 | 歌詞・音声・動画・バージョンを**1つのZIP**にまとめて保存/復元（自前ZIP実装・依存ゼロ） |
| ストレージ使用量 | `navigator.storage.estimate()` による実測表示（動画/音声/歌詞の内訳付き） |

## ローカルでの起動方法

Service Worker と IndexedDB は `file://`（ファイルを直接ダブルクリック）では動作しません。
**簡易HTTPサーバ**で起動してください。

このフォルダ（`Verse/`）で以下を実行します。

```bash
# Python がある場合（推奨）
python -m http.server 8000
# もしくは
py -m http.server 8000
```

ブラウザで `http://localhost:8000` を開きます。

> Node.js を使う場合: `npx http-server -p 8000` などでも可。

## iPhone / スマホでのファイル取り込み

本アプリは iPhone の「ボイスメモ」アプリを直接読み取ることは**しません**（直接連携なし）。
以下の方法で取り込みます。

1. **ファイルアプリから選択**: 詳細画面の「＋ アップロード」→ ファイル選択でボイスメモ/動画を選ぶ。
2. **共有 → ファイルに保存 → アップロード**: iPhoneのボイスメモ等で「共有」→「"ファイル"に保存」→ 本アプリの「＋ アップロード」から選択。

> iOS Safari は Web の「共有ターゲット（Share Target）」に事実上対応していないため、
> 共有シートに本アプリを直接表示する方式は実装していません（上記2手順で取り込めます）。

## データの保存場所と注意

- すべてのデータは**ブラウザのIndexedDB**（端末内）に保存されます。サーバーには一切送信されません。
- ブラウザの空き容量が逼迫すると、OS/ブラウザの判断で保存データが削除される可能性があります。
  - アプリ起動時に「永続化（persist）」を要求し、削除されにくくします（ブラウザにより挙動が異なります）。
  - **定期的に「データ管理 → ⬇ データをバックアップ」でZIPを保存してください。**
- 別のブラウザ / 別端末 / プライベートモードは**別のストレージ**です。データは共有されません（移行はバックアップZIPで行います）。

## GitHub Pages での公開手順

音声・動画データは端末内にのみ残るため、**GitHubにアップロードされるのはアプリのコードだけ**です（メディア本体は含まれません）。

1. GitHub で新しいリポジトリを作成する。
2. この `Verse/` フォルダの中身（`index.html` など）をリポジトリのルートに push する。
   ```bash
   cd Verse
   git init
   git add .
   git commit -m "Verse"
   git branch -M main
   git remote add origin https://github.com/<ユーザー名>/<リポジトリ名>.git
   git push -u origin main
   ```
3. リポジトリの **Settings → Pages** で、Source を `main` ブランチ / `/ (root)` に設定して保存。
4. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます。
   - すべて相対パス（`./`）で参照しているため、サブパス配信でもそのまま動作します。
5. スマホでそのURLを開き、ブラウザメニューから「ホーム画面に追加」でアプリのように使えます。

> 公開後もアプリの動作は端末内で完結し、通信・課金は発生しません。

## ブラウザ対応

- 最新の Chrome / Edge / Safari / Firefox（PC・モバイル）を想定。
- 容量上限の取得（`navigator.storage.estimate()`）非対応の環境では、保存済みサイズ合計のみ表示します（虚偽の数値は出しません）。
